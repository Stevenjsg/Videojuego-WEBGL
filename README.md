# Juego WEBGL

Para que carguen bien los assets, descargar la version GLB con texture Size: 1k.
Luego crear la carpeta public/models y dentro las carpetas para cada modelo.

- `/models/enemy/azure_automaton.glb`.
- `/models/apartment/ModernApartment.glb`
- `models/assets/flashlight.glb`
